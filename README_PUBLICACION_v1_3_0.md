# Mapa del Estado mexicano · sitio v1.3.0

Fecha de corte de la base institucional: 28 de septiembre de 2026. La base de datos sigue siendo v1.2.0 (1,598 registros, 1,770 relaciones y 78 fuentes); esta versión añade herramientas de participación y medición.

## Publicación

1. Descomprime el paquete y sube **todos sus archivos** a la raíz del repositorio `bustiflavia-prog/mapa-estado-mexicano`, reemplazando los archivos con el mismo nombre. El `index.html` y el nuevo `config_publicacion.js` deben quedar juntos en la raíz.
2. En GitHub Pages, recarga la dirección pública después de publicar. La insignia superior debe decir **v1.3.0** y debe aparecer la pestaña **Aportes**.
3. Sigue `GUIA_VISITAS_Y_APORTES.md` para activar la medición y los comentarios integrados. Hasta completar ese paso, Aportes enlaza a los reportes públicos del repositorio, siempre que Issues esté habilitado. Las visitas no se cuentan hasta configurar GoatCounter.

No subas únicamente el HTML: los enlaces de descarga apuntan a los CSV y al Excel incluidos. La búsqueda, filtros, comparación y relaciones siguen funcionando con los datos incluidos en `index.html`.

## Archivos de esta versión

- `index.html`: sitio completo.
- `config_publicacion.js`: los cuatro identificadores públicos de integración; no contiene contraseñas ni tokens.
- `GUIA_VISITAS_Y_APORTES.md`: activación paso a paso.
- `base_maestra_v1_2_0.xlsx`, CSV y reporte de cobertura v1.2.0: datos institucionales sin cambios.

Los comentarios publicados se guardan en GitHub Discussions, son visibles para cualquiera y requieren una cuenta de GitHub para escribir. Las personas visitantes no reciben permiso para alterar el repositorio ni las fichas. Las correcciones se revisan antes de incorporarlas a una versión.
