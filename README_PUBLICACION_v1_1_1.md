# Mapa del Estado mexicano · v1.1.1

Corte: 2026-09-28

Esta versión corrige y fortalece la v1.1 de publicación.

## Cambios principales
- 25 titulares superiores verificados con fuentes oficiales.
- Corrección del semáforo de calidad:
  - entidades federativas: nodo territorial, estructura interna pendiente;
  - entidades paraestatales: existencia/sectorización verificadas, estructura interna no desagregada.
- Navegación principal en dos filas, sin recorte horizontal.
- Histórico identificado como “en construcción”.
- Comparador ampliado con métricas estructurales y presets.
- Explorador de relaciones ampliado con jerarquía/adscripción, sectorización, clasificación paraestatal y sucesión documentada.
- Exportación específica de relaciones institucionales y titulares.
- Catálogo de fuentes incorpora fuentes de titularidad.
- Base maestra enriquecida con métricas derivadas para comparación.
