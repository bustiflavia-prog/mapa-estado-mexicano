# Mapa del Estado mexicano · v1.1 · publicación federal

Versión de publicación construida sobre la base federal v1.0 RC.

## Funciones incorporadas

1. Ficha institucional ampliada.
2. Sección “Sobre el proyecto”.
3. Metodología ampliada.
4. Búsqueda avanzada con filtros combinables.
5. Comparador de 2 a 4 instituciones.
6. Ruta “¿De quién depende?”.
7. Vista por sectores funcionales de navegación.
8. Indicadores dinámicos del contenido del mapa.
9. Semáforo de calidad documental.
10. Historial de versiones.
11. Interfaz de cambios en el tiempo.
12. Enlaces permanentes por institución y vista.
13. Cita automática de cada ficha.
14. Descarga individual en CSV/JSON e impresión/PDF.
15. Reporte de correcciones mediante GitHub Issues.
16. Glosario de términos.
17. Modo docente.
18. Buscador y catálogo de fuentes.
19. Red de relaciones jerárquicas, sectoriales e históricas disponibles.
20. Panel de actualizaciones recientes de la base.

## Alcance y límites

La versión es federal. La estructura interna de las 32 entidades federativas no se desagrega todavía. Las 181 entidades paraestatales aparecen individualizadas, pero no se reconstruye todavía el organigrama interno completo de cada una. La profundidad de las dependencias federales depende de las fuentes oficiales verificadas.

Una unidad no cargada no debe interpretarse como inexistente.

## Publicación en GitHub Pages

Reemplazar en el repositorio los archivos existentes por el contenido de este paquete. `index.html` debe quedar en la raíz del repositorio. GitHub Pages puede seguir desplegando desde `main / (root)`.
